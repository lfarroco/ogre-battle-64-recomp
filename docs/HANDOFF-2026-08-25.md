## What changed this session (vendored runtime — gitignored, re-apply on re-clone)

- `tools/N64ModernRuntime/librecomp/src/recomp.cpp`:
  - **External-message drainer thread** (`external_message_drainer_entry` +
    `start_external_message_drainer`): a hidden game thread (id 200, priority 5,
    entry VRAM 0x8E000000) that loops `wait_for_external_message` +
    `check_running_queue`, spawned in `wait_for_game_started` after
    `on_init_callback`. Required because the runtime only drains external
    messages (VI/AI/SP/SI events) when a game thread calls
    `osSendMesg`/`osRecvMesg`, and OB64's boot blocks every game thread waiting
    for the VI retrace event (main thread busy-spins). **Priority must stay low
    (5): this runtime schedules higher numbers first, and priority 30 starved
    the game thread (pri 10).**
- `tools/N64ModernRuntime/librecomp/src/sp.cpp`: `osSpGetStatus_recomp`
  (returns `SP_STATUS_HALTED`).
- `tools/N64ModernRuntime/ultramodern/src/mesgqueue.cpp`: debug-printf tweak in
  `do_recv` (queue address in the blocked-on-receive log).
- `tools/N64ModernRuntime/ultramodern/src/events.cpp`, `mesgqueue.cpp`,
  `include/ultramodern/ultramodern.hpp`: temporary debug instrumentation
  **removed** (debug_printf is back to a no-op).
- `tools/N64Recomp/src/symbol_lists.cpp`: added `osSpGetStatus` to
  `reimplemented_funcs`. **N64RecompCLI was rebuilt** (`tools/N64Recomp/build`).
